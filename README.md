# CadastroClientes

Sistema Web de Cadastro e Gerenciamento de Clientes desenvolvido com C#, ASP.NET Core, HTML, CSS, JavaScript, Bootstrap e jQuery.

## Funcionalidades

- Cadastro de clientes
- Consulta de registros
- Edição de informações
- Exclusão de clientes
- API REST documentada com Swagger

## Tecnologias Utilizadas

- C#
- ASP.NET Core
- HTML
- CSS
- JavaScript
- jQuery
- Bootstrap
- Swagger

## Sobre o Projeto

O projeto utiliza um arquivo de texto ("Banco de Dados.txt") para armazenar os dados dos clientes, simulando a persistência das informações. Como evolução futura, pretendo integrar um banco de dados SQL para tornar a aplicação mais robusta e escalável.
